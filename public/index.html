ℹ️ Model Methodology & Formulas
1. IMD Heat Index (Rothfusz Regression):
HI = f(Air Temp °C, Relative Humidity %)
2. Vulnerability Index (VI):
VI = 0.455(Population) + 0.364(Facilities) + 0.182(LowVeg)
3. Human Heat Stress Index (HHSI):
HHSI = HI × (1 + 0.30 × VI)
